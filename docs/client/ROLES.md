# الصلاحيات والأدوار

النظام فيه دورين بس: **أدمن** و**مشغّل**. كل مستخدم بياخد واحد منهم وقت ما ينضاف، وبتقدر تغيّر الدور في أي وقت من لوحة الإدارة. القسم هذا بيشرحلك الفرق بينهم، مين المفروض ياخد كل دور، وكيف بتضيف أو بتلغي وصول مستخدم.

> 💡 **الدور (Role)** — هو الصلاحية اللي محددة لكل مستخدم داخل النظام: شو بيقدر يشوف وشو بيقدر يعمل. مش اسم وظيفة، هو إعداد تقني بسيط بيحدد كل واحد وين بيقدر يوصل.

---

## الدورين بالمختصر

| الدور | مين المفروض ياخده | شو بيشوف |
|---|---|---|
| **أدمن** (Admin) | صاحب الحساب أو الشخص المسؤول عن إعدادات النظام (أنت، أو شريك موثوق) | كل شي: أداة السحب العادية + لوحة الإدارة الكاملة (`⚙️ الإدارة`) |
| **مشغّل** (Operator) | الموظف/الموظفة اللي بيسحبوا المنتجات يوميًا | أداة السحب فقط — بدون وصول للوحة الإدارة إطلاقًا |

الشارة اللي بتظهر جنب اسم كل مستخدم بأعلى الشاشة بتأكد له/لها الدور الحالي: **"أدمن"** أو **"مشغّل"**.

## جدول الصلاحيات التفصيلي

هاد الجدول مبني تمامًا على الفحص الحقيقي بالكود (كل مسار بالنظام بيتحقق من الدور قبل ما ينفّذ أي إجراء حساس).

| الإجراء | مشغّل | أدمن | ملاحظة |
|---|:---:|:---:|---|
| تسجيل الدخول / الخروج | ✅ | ✅ | متاح للكل |
| سحب منتج (رابط أو بحث باسم) | ✅ | ✅ | العملية الأساسية اليومية |
| اكتشاف منتجات بالجملة (فئة / زحف دومين) | ✅ | ✅ | |
| مراجعة الصور والفيديو وتعديل بيانات المنتج | ✅ | ✅ | |
| الحفظ للمتجر أو تنزيل ZIP | ✅ | ✅ | |
| اختيار وجهة الحفظ من القائمة (المتاجر المحفوظة مسبقًا) | ✅ | ✅ | بس اختيار وجهة موجودة، مش إضافة وحدة جديدة |
| فتح لوحة الإدارة (`⚙️ الإدارة`) | ❌ | ✅ | الرابط أصلًا ما بيظهر إلا للأدمن، وحتى لو حد جرّب يفتح الرابط مباشرة بينرجّع للصفحة الرئيسية |
| إضافة/تعديل/حذف مفاتيح مزوّدي الخدمة (Anthropic وOpenAI وremove.bg وغيرهم) | ❌ | ✅ | قسم "🧩 التكاملات والمفاتيح" |
| فحص اتصال المفاتيح (Test + رصيد) | ❌ | ✅ | |
| إضافة/تعديل/حذف متجر وجهة (Store) | ❌ | ✅ | قسم "🏬 وجهات الحفظ — متاجر متعددة" |
| فحص توافق متجر (Test compatibility) | ❌ | ✅ | |
| عرض قائمة المتاجر (بدون التوكن نفسه) | ✅ | ✅ | التوكن السري ما بيترجع أبدًا لأي دور، حتى الأدمن — بس بيظهر إشارة إذا محفوظ أو لأ |
| إضافة مستخدم جديد | ❌ | ✅ | قسم "👥 المستخدمون والصلاحيات" |
| تغيير دور مستخدم (ترقية/تنزيل) | ❌ | ✅ | ما بتقدر تنزّل رتبة آخر أدمن بالنظام — النظام برفض العملية تلقائيًا لمنع ما يضل الحساب بلا أدمن |
| تعيين كلمة مرور جديدة لمستخدم تاني | ❌ | ✅ | |
| حذف مستخدم | ❌ | ✅ | ما بتقدر تحذف حسابك انت، وما بتقدر تحذف آخر أدمن بالنظام |
| تغيير كلمة السر عبر "نسيت كلمة المرور" | ✅ | ✅ | متاح لأي مستخدم لحاله من صفحة الدخول |

**خلاصة الفرق:** المشغّل بيشتغل بس داخل أداة السحب (البحث، السحب، المراجعة، الحفظ). الأدمن بس هو اللي بيقدر يلمس أي شي حساس: مفاتيح الخدمات المدفوعة، المتاجر اللي بتنحفظ عليها المنتجات، وحسابات باقي المستخدمين.

> ⚠️ لا يوجد دور ثالث "بينشوف بس" أو صلاحيات جزئية أدق من هيك (متل "بيقدر يعدّل المتاجر بس مش المفاتيح"). الاختيار محصور بأدمن أو مشغّل فقط.

## كيف بتضيف مستخدم جديد

1. سجّل دخولك بحساب أدمن.
2. اضغط رابط **"⚙️ الإدارة"** بأعلى الشاشة (ما بيظهر إلا لحسابات الأدمن).
3. انزل لقسم **"👥 المستخدمون والصلاحيات"**.
4. تحت قائمة المستخدمين، بلاقي نموذج **"➕ إضافة مستخدم"**. عبّي:
   - **الإيميل** — إيميل الشخص الجديد.
   - **كلمة مرور مبدئية** — لازم ٨ أحرف على الأقل. هاي كلمة مرور مؤقتة، الشخص بيقدر يغيّرها بعدين لحاله.
   - **الدور** — اختر **"مشغّل"** (الاختيار الافتراضي) إذا الشخص بده يستخدم أداة السحب بس، أو **"أدمن"** إذا بده صلاحية كاملة.
5. اضغط **"➕ أضف المستخدم"**.
6. ابعت للشخص الإيميل وكلمة المرور المبدئية (بطريقة آمنة — انظر تنبيهات الأمان تحت). بيقدر يسجّل دخول فورًا، وبينصحه النظام إنه يغيّرها من "نسيت كلمة المرور" بصفحة الدخول.

## كيف بتلغي وصول مستخدم (تعطيل الحساب)

النظام ما فيه زر "تعطيل مؤقت" — فيه بس خيارين فعليين لقطع وصول شخص، وهنن:

### الخيار الأول (الموصى فيه): احذف الحساب نهائيًا
1. من نفس قسم **"👥 المستخدمون والصلاحيات"** بلوحة الإدارة، دور على صف المستخدم.
2. اضغط زر **🗑** جنب اسمه.
3. أكّد الحذف. الحساب بينحذف فورًا ومابيقدر يسجّل دخول بعدها إطلاقًا.

> ⚠️ ما بتقدر تحذف حسابك انت وانت مسجّل دخول فيه. وما بتقدر تحذف آخر حساب أدمن متبقّي بالنظام — لازم يضل في أدمن واحد ع الأقل شغّال دايمًا.

### الخيار الثاني: اقطع الوصول مؤقتًا بدون حذف البيانات
إذا بدك توقف وصول شخص بسرعة بس ما بدك تحذف حسابه (مثلًا إجازة طويلة أو تحقيق داخلي)، اضغط زر **🔑** جنب اسمه وحطّله كلمة مرور جديدة ما حدا غيرك بيعرفها. هيك حسابه بيضل موجود بس ما بيقدر يسجّل دخول لحد ما تعطيه كلمة السر الجديدة.

## تنبيهات أمان — بلغة بسيطة

**ما تشارك حسابك مع حدا.** كل حساب لازم يكون لشخص واحد بس. إذا اشتغل شخصين بنفس الحساب، ما رح تعرف مين عمل شو، ولو انسرق الحساب رح يكون أصعب تعرف كيف. أعطِ كل موظف/ة حساب خاص فيهم.

**ما تبعث كلمة السر بطريقة مكشوفة.** لما تضيف مستخدم جديد وتاخد كلمة المرور المبدئية، ابعتها بطريقة أأمن قد ما تقدر (رسالة خاصة، مكالمة، أو شخصيًا) — مش برسالة عامة أو مجموعة واتساب فيها ناس كتير. واطلب من الشخص يغيّرها أول ما يسجّل دخول.

**أعطِ أقل صلاحية كافية (مبدأ "أقل صلاحية ممكنة").** معظم فريقك محتاج دور **مشغّل** بس — هو كل اللي محتاجينه عشان يسحبوا ويحفظوا منتجات. دور **أدمن** خليه لأقل عدد ممكن من الناس (أنت، وشريك موثوق إذا لازم)، لأنه بيقدر يشوف ويغيّر إعدادات حساسة: مفاتيح خدمات مدفوعة، وجهات حفظ المنتجات، وحسابات باقي الموظفين. كل ما قلّ عدد الأدمن، قلّت فرصة إن غلطة أو حساب مخترق يأثر عالنظام كله.

**راجع قائمة المستخدمين بين فترة وفترة.** افتح "👥 المستخدمون والصلاحيات" كل شهر أو شهرين وشوف: في حسابات لموظفين ما عادوا شغالين معك؟ احذفهم. في حساب أدمن أكتر من اللازم؟ نزّل رتبته لمشغّل إذا ما بده يدير إعدادات النظام.

**كلمة المرور لازم تكون قوية.** النظام بيفرض ٨ أحرف كحد أدنى على أي كلمة مرور (سواء مبدئية أو مُعاد تعيينها) — بس الأفضل تستخدموا كلمات أطول وأصعب تخمين من الحد الأدنى.
